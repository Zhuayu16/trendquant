# TrendQuant 量化策略实验报告

> 生成时间：2026-08-31 01:10  
> 数据源：`yfinance`（前复权日线）  
> 运行环境：Python 3.13.5 / pandas 2.2.3 / numpy 2.2.6

## 1. 实验设置

- 样本区间：**2019-01-02 ~ 2026-08-28**（各标的实际可得交易日的交集区间见数据缓存）
- 股票池（8 只，等权合并）：600519 贵州茅台、601318 中国平安、300750 宁德时代、002594 比亚迪、600036 招商银行、600030 中信证券、601899 紫金矿业、600900 长江电力
- 策略：买入持有（基准）、双均线交叉（20/60）、MACD（12/26/9）、RSI 均值回归（14）、布林带均值回归（20, 2σ）、时序动量（120 日）、ML 梯度提升（5 日方向）
- 成本模型：佣金 0.025%（双边）+ 印花税 0.05%（卖出）+ 滑点 0.10%（双边）
- 执行假设：t 日收盘出信号，t+1 开盘成交；仅做多、0/1 仓位
- ML 设定：HistGradientBoosting，标签 = 未来 5 日涨跌方向，walk-forward 5 折（gap=5），建仓阈值 p>0.55

## 7. 结论要点

- 组合层面（等权）年化收益最高的主动策略为 **MACD（12/26/9）**（14.24%），夏普比率最高的是 **RSI 均值回归（14）**（1.046）。
- 配对 t 检验（p<0.05）下**显著劣于买入持有基准**的策略：双均线交叉（20/60）、RSI 均值回归（14）、布林带均值回归（20, 2σ）、时序动量（120 日）、ML 梯度提升（5 日方向）——信号滞后与双边交易成本侵蚀了收益（日收益差显著为负，p<0.05）。
- 在 5% 显著性水平下，**没有任何主动策略在收益上显著优于买入持有基准**——这与弱式有效市场假说在本样本上的表现一致。但注意风险口径的差异：基准的最大回撤为 -26.56%，而部分主动策略（如 MACD、RSI 均值回归）以显著更低的回撤取得了统计上与基准无显著差异的收益，属于**风险调整口径下的可行替代**。
- 日均收益显著异于零（p<0.05）的策略：买入持有（基准）、双均线交叉（20/60）、MACD（12/26/9）、RSI 均值回归（14）。
- ML 梯度提升模型在 12360 个 walk-forward 样本外方向预测中命中 6282 个（50.83%，二项检验 p=0.03393，显著高于 50%）；但方向上的微弱优势不足以覆盖交易成本与 0.55 建仓阈值带来的机会成本，其净收益显著低于基准，说明**预测精度 ≠ 策略盈利能力**。
- 上述结果对交易成本、参数选择与样本期均敏感，仅供方法论研究参考，不构成投资建议。
